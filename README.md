# Rinse v2.0

Rinse 是一款 Android Laundry 设备状态查询 App。首次使用时预置原有五台辅2地下机器，用户还可以从左侧菜单选择「添加机器」，使用摄像头扫描设备二维码、命名，并保存在当前手机上。所有机器（包括预置机器）均可通过侧边栏「删除机器」移除；删除后不会自动重新添加。无需账户或云同步，卸载 App 或清除应用数据会重置设备列表。

## 使用

1. 打开左侧菜单，点击「添加机器」→「打开摄像头扫描二维码」，允许摄像头权限。
2. 对准胖乖生活设备二维码（须为 `https://h5.qiekj.com/skip?...NQT=...` 地址）。不支持其他厂商二维码；同一 NQT 的设备不能重复添加。
3. 填写名称并保存，设备会出现在「Laundry 查询」里，点击「开始查询」即可查询。状态仍仅显示等待查询、查询中、可用、使用中、不可用或未知。
4. 删除机器：打开左侧菜单的「删除机器」，勾选一台或多台（包括预置机器），点击「确认删除」，再在弹窗中点击「确认删除」。取消弹窗不会删除；删除后列表在本机持久保存。

## 查询原理

每台设备沿用原有 WebView 查询逻辑：访问二维码对应的胖乖生活 H5 地址，等待网页跳转与渲染，然后读取最终 URL 和网页文字。命中「设备工作中」等词显示使用中；停用、维修或离线显示不可用；正常进入 h5.qiekj.com 且没有上述信息则显示可用，加载失败/超时/未识别为未知。它并非官方状态 API；网页发生变化时可能需要更新判断逻辑。仅手动查询，不自动轮询。
